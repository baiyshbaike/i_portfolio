Backend-поддержка полного цикла

От проектирования модели данных и REST API до Docker-deployment, настройки Nginx и поддержки production-среды.

Надёжные backend-системы на Django, .NET Core, PostgreSQL и Docker

Я разрабатываю backend-сервисы для государственных, корпоративных и финтех-процессов, уделяя внимание чистым границам API, консистентности базы данных, повторяемому deployment и поддерживаемой production-эксплуатации.

  • Разработка на Django, Django REST Framework, .NET Core и Blazor.
  • Проектирование схем PostgreSQL, миграции, индексы и оптимизация SQL.
  • Docker, Linux, Nginx, Kestrel, CI/CD и усиление безопасности.

Мой недавний опыт включает онлайн-продажу железнодорожных билетов, интеграцию Freedom Pay, государственные информационные системы и систему электронной очереди для клиники.

Также могу помочь с code review, технической координацией и production-troubleshooting там, где важны качество backend, безопасность транзакций и дисциплина deployment.
